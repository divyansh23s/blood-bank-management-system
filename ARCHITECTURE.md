Scoring Algorithm Flow\n\n```\n                          calculateScore(donor, lat, lng)\n                                  │\n                    ┌─────────────┼─────────────┐\n                    ▼             ▼             ▼\n            ┌────────────┐ ┌────────────┐ ┌──────────┐\n            │ FACTOR 1   │ │ FACTOR 2   │ │ FACTOR 3 │\n            │ Active     │ │ Eligible   │ │ Age      │\n            │ Status     │ │ to Donate  │ │ Range    │\n            └──────┬─────┘ └──────┬─────┘ └────┬─────┘\n                   │              │            │\n            isActive   lastDonation       age >= 18\n            == true    >= 90 days        && <= 50\n                   │              │            │\n                   │              │            │\n              +20 points      +30 points    +10 points\n                   │              │            │\n                   └──────────────┼────────────┘\n                                  │\n                                  ▼\n                        ┌──────────────────┐\n                        │   SUB_TOTAL      │\n                        │   (0-60 points)  │\n                        └────────┬─────────┘\n                                 │\n                                 ▼\n                        ┌──────────────────────┐\n                        │ FACTOR 4: Distance   │\n                        │ (Geolocation)        │\n                        └────────┬─────────────┘\n                                 │\n                    lat/lng available?\n                    │\n              YES   │    NO\n               ✓    ▼    ✗\n                    │\n            ┌───────┴────────┐\n            ▼                ▼\n      Calculate         Distance\n      Euclidean         Score = 0\n      Distance\n            │\n      distance =\n      √((Δlat)² + (Δlng)²)\n            │\n            ▼\n      Distance Score =\n      max(0, 30 - distance * 10)\n      (0-30 points)\n            │\n            └────────┬────────┘\n                     ▼\n          ┌──────────────────────┐\n          │   TOTAL SCORE        │\n          │   SUB_TOTAL +        │\n          │   DISTANCE_SCORE     │\n          │   = 0-90+ points     │\n          └─────────┬────────────┘\n                    │\n                    ▼\n          RETURN score (rounded\n          to 1 decimal place)\n```\n\n---\n\n## Request-Response Cycle\n\n###
